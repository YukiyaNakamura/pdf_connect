# PDF結合

ブラウザだけで動くPDF結合アプリです。ファイルはサーバーに送信されません。

## 機能

- **PDFを追加** — ドラッグ＆ドロップ、またはファイル選択（複数可）
- **順番を変更** — 各ファイルの ↑ / ↓ ボタン（スマホ対応）、✕ で削除
- **結合してダウンロード** — ファイル名を指定して保存（`.pdf` は自動付与、使えない文字は `_` に置換）
- **エラー表示** — パスワード付き・破損・PDF以外のファイルは一覧上で赤く表示し、理由を表示。エラーが残っている間は結合せず、該当ファイル名を示す

## 使い方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
```

`dist/` は静的ファイルなので、GitHub Pages・Netlify などにそのまま配置できます。

## 構成

- `src/pdf.js` — PDFの検証・結合・ファイル名処理（[pdf-lib](https://pdf-lib.js.org/) を使用）
- `src/main.js` — 画面の状態管理と描画
- `src/style.css` — スタイル（ダークモード対応）
- `test/pdf.test.js` — `src/pdf.js` のテスト
